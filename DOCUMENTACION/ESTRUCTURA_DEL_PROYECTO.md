# Estructura del proyecto

```text
belladona-joyeria/
├── public/                 Recursos estáticos locales cuando se incorporen
├── src/
│   ├── App.jsx             Navegación, páginas y componentes principales
│   ├── data.js             Marca, catálogo, galería, videos y preguntas frecuentes
│   ├── main.jsx            Punto de entrada React y enrutador
│   └── styles.css          Estilos responsive y temas
├── DOCUMENTACION/          Guías del proyecto
├── .env.example            Variables comerciales de ejemplo
├── index.html              Metadatos de la página
├── package.json            Dependencias y comandos
└── vite.config.js          Configuración de Vite
```
