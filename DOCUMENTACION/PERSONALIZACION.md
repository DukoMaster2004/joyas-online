# Personalización

1. Reemplaza el catálogo de muestra en `src/data.js` con productos y datos confirmados.
2. No publiques los productos de demostración como inventario oficial. Deja `price: null` mientras el precio no esté confirmado.
3. Cambia las imágenes temporales por imágenes propias o con licencia compatible. No se repiten imágenes para completar artificialmente una cantidad.
4. Completa `videoSlots` con videos reales autorizados; los campos vacíos no muestran videos de ejemplo.
5. Configura WhatsApp, correo e Instagram siguiendo `CONFIGURACION.md`.
6. Cambia colores, tamaños y espaciado mediante las variables de `src/styles.css`.
7. Actualiza `faqs` con respuestas oficiales para que el asistente local no comparta información no confirmada.

La galería actual tiene 14 referencias visuales temporales únicas. Aún requiere reemplazo o ampliación para alcanzar las 30 fotografías oficiales solicitadas.
